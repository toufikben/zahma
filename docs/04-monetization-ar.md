## 2. هيكل الطبقات

### 2.1 الطبقة المجانية — "زحمة أساسي"
**الهدف:** النمو، الاحتفاظ، توليد البيانات.

| الميزة | الحد |
|--------|------|
| خريطة حية | كامل |
| مسار واحد (الأسرع) | كامل |
| بحث وجهة | كامل |
| **إشعار واحد يومياً** | 1 |
| تاريخ | 3 أيام |
| نقاط ساخنة | عرض أساسي |
| تحذير طقس | 24 ساعة مقدماً |
| إعلانات | بانر سفلي (لا intersitial) |
| مسار محفوظ | 1 |

**فلسفة:** المجاني يجب أن يكون تطبيقاً حقيقياً يعمل. المستخدم الذي لا يدفع يجب أن يشعر أنه استفاد، وإلا يترك التطبيق ولا يوصي به.

### 2.2 الطبقة المدفوعة — "زحمة بلس" ★ الأساس
**الهدف:** 60% من الإيراد.

| الميزة | التفصيل |
|--------|---------|
| **مستشار الانطلاق** | غير محدود |
| **التنبؤ** | 15/30/60/120 دقيقة |
| **3 مسارات** | أسرع / أكثر استقراراً / بديل |
| **إشعارات ذكية** | حتى 10/يوم، مع توقيت محسوب |
| **إعادة توجيه تلقائي** | عند الانهيار |
| **الخريطة الحرارية** | نمطك الشخصي |
| **تاريخ 90 يوماً** | مع تحليل |
| **تحذير فيضان** | دقيق (60 دقيقة) |
| **متعدد الوسائط** | مترو/ترامواي/تلفريك |
| **بلا إعلانات** | — |
| **مسارات محفوظة** | 10 |
| **دقة الثقة** | p10–p90 معروض |

**السعر:**
- شهري: **490 دج** (~$3.3)
- سنوي: **4,900 دج** (~$33) — خصم 17%
- أسبوعي: **150 دج** (للموسميين)

**لماذا 490؟**
- أقل من 2.5% من الحد الأدنى للأجر.
- أقل من رحلة تاكسي واحدة في العاصمة (600–1200 دج).
- أعلى من "مجاني" بما يكفي ليغطي التكلفة (≈$0.45/مستخدم/شهر تكلفة بنية تحتية عند الحجم).
- يقبل "التقريب النفسي" في المتاجر.

### 2.3 الطبقة المهنية — "زحمة برو"
**الهدف:** سائقو التوصيل والتاكسي — أعلى استعداد للدفع، أعلى قيمة.

| الميزة | التفصيل |
|--------|---------|
| كل ميزات بلس | — |
| **مسارات غير محدودة** | + تخطيط متعدد المحطات (حتى 10) |
| **إشعارات غير محدودة** | مع أولويات |
| **توقعات لكل ساعة** | لليوم التالي |
| **مقارنة أيام** | "أمس كان أفضل 15 دقيقة" |
| **تسجيل الرحلة** | تصدير CSV |
| **وضع "أفضل وقت للعودة"** | محسوب |
| **دعم أولوية** | رد < 12 ساعة |
| **حسابان** | (هاتف + تابلت) |

**السعر:**
- شهري: **990 دج** (~$6.6)
- سنوي: **9,900 دج**
- 3 أشهر: **2,700 دج**

### 2.4 الطبقة المؤسسية — "زحمة أسطول" (B2B)
**الهدف:** الشركات، شركات التوصيل، اللوجستيك.

| الحزمة | السعر |
|--------|-------|
| 5 سائقين | 3,900 دج/شهر |
| 15 سائق | 9,900 دج/شهر |
| 50 سائق | 27,000 دج/شهر |
| 200+ | تفاوض (1,500 دج/سائق/شهر) |

**الميزات:**
- لوحة تحكم (أين السائقون، أي طريق، أي تأخير)
- API للتكامل
- تقارير أداء أسبوعية
- تخصيص المسارات
- إدارة الفريق

## 4. قمع التحويل

### 4.1 المراحل
```
زائر المتجر (100%)
   ↓ تحميل
مستخدم جديد (35%)
   ↓ التسجيل + الموافقة
مستخدم مُفعّل (60%)  ← أضاف مساراً، شاهد خريطة
   ↓ الأسبوع 1: تجربة مدفوعة مجانية
مستخدم مُدرك للقيمة (40%)  ← استخدم "متى أخرج؟" 3 مرات
   ↓ نهاية التجربة
مستخدم حر (25%)  ← يبقى مجانياً
   ↓ لحظة الحاجة (تأخر فعلي / طريق مسدود)
مشترك (4–6%)
```

### 4.2 نقاط التحويل (Paywall Placement)

| النقطة | الرسالة | معدل التحويل المتوقع |
|--------|---------|----------------------|
| نهاية التجربة (14 يوماً) | "انتهت تجربتك. 490 دج/شهر لتستمر." | 15–20% |
| محاولة استخدام مستشار الانطلاق (مجاني) | "هذه الميزة في بلس. جرّبها مجاناً 14 يوماً." | 8–12% |
| بعد إشعار مجاني | "لو كنت مشتركاً، كنت ستعرف هذا قبل 25 دقيقة." | 3–5% |
| بعد رحلة تأخر فيها 20+ دقيقة | "تأخرت 22 دقيقة اليوم. بلس كان سيوفر لك 15 منها." | 6–9% |
| الإشعار الثاني في اليوم | "وصلت حدّك المجاني. ترقية؟" | 10–14% |
| محاولة عرض تاريخ > 3 أيام | "سجل أطول في بلس." | 4–6% |

### 4.3 المبدأ الذهبي
> **لا تضع جداراً في اللحظة التي يكون فيها المستخدم في السيارة ومتأخراً.** هذا يولّد كرهاً وإلغاءات.
> الجدار يجب أن يكون **قبل** لحظة الحاجة (عند التخطيط)، لا **خلالها**.

**الاستثناء:** إشعار "طريقك مزدحم" في اللحظة الحرجة **يجب أن يظل مجانياً** — لكن بمعلومة ناقصة (بدون البديل، بدون توقيت دقيق). هذا يخلق الحاجة دون إحباط.

## 5. الدفع — التنفيذ

### 5.1 الأولوية 1: Google Play Billing (Android)
- 85% من السوق الجزائري أندرويد.
- الدفع بالدينار مدعوم (109–45,000 دج).
- يمكن الدفع ببطاقة أو رصيد هاتف أو بطاقة هدايا.
- **عمولة Google: 15%** (للمشتركين بعد السنة الأولى) أو 30% (السنة الأولى).
- التحقق من الإيصال على الخادم إلزامي.

### 5.2 الأولوية 2: Apple App Store (iOS)
- سوق أصغر لكن قدرة شراء أعلى.
- الدفع متاح في الجزائر (App Store storefront موجود).
- عمولة 15–30%.

### 5.3 الأولوية 3: Chargily / SATIM (خارج المتاجر)
- **لا يمكن** استخدامه لبيع محتوى رقمي داخل تطبيق أندرويد/آيفون (سياسة المتاجر).
- **يمكن** استخدامه لـ:
  - اشتراك ويب (لوحة تحكم الأسطول)
  - فواتير B2B
  - اشتراك عبر الموقع (خارج التطبيق) — لكن التطبيق لا يمكنه توجيه المستخدم للدفع خارجه (سياسة المتاجر)
- **القيمة:** للأسطول والشركات، حيث الدفع بالفواتير والتحويل البنكي هو القاعدة.

### 5.4 الأولوية 4: تحويل بنكي / CCP (B2B فقط)
- للعقود السنوية الكبيرة.
- فاتورة + وصل + تفعيل يدوي.

### 5.5 جدول التنفيذ
| المرحلة | طريقة الدفع |
|---------|-------------|
| MVP | Play Billing فقط |
| +4 أسابيع | + App Store |
| +8 أسابيع | + لوحة ويب للأسطول (Chargily) |
| +12 أسبوع | + فواتير B2B |

## 6. اقتصاد الوحدة

### 6.1 الافتراضات
| المتغير | القيمة |
|---------|--------|
| تكلفة البنية التحتية / مستخدم نشط / شهر | $0.04 (عند 10k) → $0.03 (عند 100k) |
| تكلفة حركة/بلاطات / مستخدم نشط | $0.02 |
| دعم / مستخدم | $0.01 |
| **إجمالي التكلفة المتغيرة** | **$0.07/مستخدم/شهر** |

### 6.2 الحساب عند 10,000 مستخدم نشط شهرياً
```
الإيراد:
  مشتركون: 10,000 × 4.5% = 450
  متوسط الإيراد الصافي/مشترك (بعد عمولة 20%): 490 دج × 0.8 = 392 دج ≈ $2.6
  إيراد شهري: 450 × $2.6 = $1,170

التكلفة:
  بنية تحتية: $650
  متغير: 10,000 × $0.07 = $700
  إجمالي: $1,350

النتيجة: -$180/شهر  ❌ خسارة طفيفة
```

### 6.3 عند 50,000 مستخدم
```
الإيراد:
  مشتركون: 50,000 × 4.5% = 2,250
  إيراد: 2,250 × $2.6 = $5,850

التكلفة:
  بنية تحتية: $2,400
  متغير: 50,000 × $0.06 = $3,000
  إجمالي: $5,400

النتيجة: +$450/شهر  ⚠️ هامش ضيق
```

### 6.4 عند 100,000 مستخدم (مع B2B)
```
الإيراد:
  B2C: 100,000 × 5% = 5,000 × $2.6 = $13,000
  B2B: 30 شركة × 15 سائق × $5 = $2,250
  إجمالي: $15,250

التكلفة:
  بنية تحتية: $4,600
  متغير: $6,000
  إجمالي: $10,600

النتيجة: +$4,650/شهر  ✅ هامش 30%
```

### 6.5 الاستنتاجات الحرجة
1. **B2C وحده لا يكفي في الجزائر.** الهامش رقيق جداً.
2. **B2B (الأسطول) ضروري** — 30 شركة تعطي نفس إيراد 900 مشترك فردي بتكلفة دعم أقل.
3. **الإعلانات ضرورية للمجاني** — ليست ترفاً.
4. **تقليل تكلفة الحركة/البلاطات** أولوية هندسية (استضافة ذاتية).
5. **الحجم هو كل شيء** — عند 10k المستخدم المشروع خاسر.

## 7. الإعلانات — الطبقة المجانية

### 7.1 المبدأ
الإعلان يجب أن يكون **غير مزعج ولا يضر بالسلامة**.

### 7.2 الأشكال المسموحة
| الشكل | أين | متى |
|-------|-----|-----|
| بانر سفلي | شاشة الخريطة | دائماً (مجاني فقط) |
| بطاقة أصلية (native) | بين بطاقات المسارات | عند التخطيط |
| إعلان مكافأة | "شاهد إعلاناً = يوم بلس مجاناً" | اختياري |

### 7.3 المحظور
- ❌ إعلان بيني (interstitial) أثناء الملاحة — خطر أمني
- ❌ إعلان صوتي
- ❌ إعلان يغطي الخريطة
- ❌ إعلان عند فتح التطبيق في السيارة

### 7.4 الإيراد المتوقع
- eCPM في الجزائر: $0.3–$1.2 (منخفض عالمياً)
- 1000 مستخدم مجاني × 3 مشاهدات/يوم × $0.6/1000 = **$1.8/يوم = $54/شهر**
- **مهمل.** لا تبنِ على الإعلانات. هي مكمّل صغير.

**بديل أفضل:** رعاية محلية (وكالة سيارات، تأمين، بنك، متجر إطارات) — إعلان واحد مدفوع مقدماً بـ50,000 دج/شهر من راعٍ واحد يعطي أكثر من 30,000 مشاهدة.

## 8. استراتيجية النمو

### 8.1 المرحلة 1: الكثافة قبل الانتشار (أشهر 1–4)
- **هدف:** 10 محاور، 5,000 مستخدم، كثافة عالية.
- **القنوات:**
  - مجموعات فيسبوك المحلية (كل بلدية لها مجموعتها)
  - تيك توك: مقاطع "قبل/بعد" (خرجت 07:00 وصلت 08:20 / خرجت 06:45 وصلت 07:50)
  - سائقو التاكسي والتوصيل: عرض برو مجاني 3 أشهر مقابل تقارير
- **رسالة:** "لا تخمّن. اخرج في الوقت الصحيح."

### 8.2 المرحلة 2: الشبكة (أشهر 5–9)
- دعوة صديق = أسبوع بلس
- شراكة مع صفحات مرور محلية
- محتوى أسبوعي: "أخطر 5 نقاط هذا الأسبوع"

### 8.3 المرحلة 3: الشركات (أشهر 10–18)
- بيع مباشر لشركات التوصيل
- عرض تجريبي 30 يوماً
- دراسة حالة: "وفّرنا X ساعة/سائق/شهر"

### 8.4 قنوات يجب تجنّبها
- إعلانات مدفوعة واسعة قبل إثبات الاحتفاظ (حرق مال)
- ASO عدواني (لا فائدة قبل التقييمات)
- شراء مستخدمين

## 9. التسعير — سيناريوهات بديلة

### 9.1 السيناريو A: تسعير أعلى (990 دج)
- ✅ إيراد أعلى لكل مشترك
- ❌ تحويل أقل بكثير (السوق حساس)
- **الحكم:** ❌ مرفوض للبداية. جرّبه لاحقاً كاختبار A/B.

### 9.2 السيناريو B: تسعير منخفض جداً (199 دج)
- ✅ تحويل عالٍ
- ❌ لا يغطي التكلفة (بعد العمولة، صافي ~$0.9)
- **الحكم:** ❌ مرفوض. لكن **249 دج** كخطة "خفيفة" (بلا متعدد الوسائط) ممكن.

### 9.3 السيناريو C: نموذج "الدفع عند الاستخدام" (Pay-per-use)
- "5 استشارات انطلاق بـ100 دج"
- ✅ لا التزام، مناسب للموسميين
- ❌ معقد تقنياً، إيراد غير متوقع
- **الحكم:** ⚠️ اختبره في V2 كخيار ثالث.

### 9.4 السيناريو D: مجاني بالكامل + بيانات
- بيع بيانات حركة مجهولة للبلديات/الباحثين
- ✅ لا حاجز دخول ⇒ نمو سريع
- ❌ سوق البيانات في الجزائر غير ناضج، وإيراده غير مضمون
- **الحكم:** ⚠️ احتفظ به كفرع إيراد مستقبلي، لا كأساس.

### 9.5 التوصية النهائية
```
490 دج/شهر    ← الخطة الرئيسية
4,900 دج/سنة  ← الخطة المفضلة (توفير 17%)
990 دج/شهر    ← برو للمهنيين
3,900 دج/شهر  ← أسطول 5 سائقين
+ طبقة مجانية سخية + إعلان راعٍ واحد
```

## 10. مؤشرات صحة النموذج التجاري

| المؤشر | الهدف | متى نتحقق |
|--------|-------|-----------|
| تحويل مجاني ← مدفوع | ≥ 4% | 3 أشهر بعد الإطلاق |
| Churn شهري | ≤ 6% | 3 أشهر |
| LTV | ≥ 4,000 دج | 6 أشهر |
| CAC | ≤ 1,200 دج | 6 أشهر |
| LTV/CAC | ≥ 3.0 | 6 أشهر |
| ARPU | ≥ 25 دج/مستخدم نشط/شهر | 6 أشهر |
| هامش إجمالي | ≥ 60% | 12 شهراً |
| إيراد B2B / إجمالي | ≥ 20% | 12 شهراً |

**قاعدة القرار:** إذا لم يتحقق تحويل 4% و LTV/CAC 3.0 بعد 6 أشهر من الإطلاق مع 20k مستخدم — أعد النظر في السعر أو المنتج، لا في التسويق.

## 11. ما نبيعه فعلاً (الرسالة التسويقية)

لا نبيع "خريطة". نبيع:

| الرسالة | الجمهور | لماذا تعمل |
|---------|---------|------------|
| "اعرف متى تخرج قبل أن تخرج." | الموظف | يحل الألم الأساسي |
| "وفّر 20 دقيقة كل يوم = 8 ساعات شهرياً." | الجميع | يحوّل الوقت إلى مال |
| "لا تفقد توصيلة بسبب الزحمة." | سائق التوصيل | يحوّل مباشرة إلى دخل |
| "لا تفاجئك الطرق المغلقة." | الجميع | يقلل القلق |
| "اعرف أن المطر سيغلق طريقك قبل ساعة." | سكان المناطق المعرضة | أمان |
| "أفضل وقت للعودة، لا فقط للذهاب." | الجميع | ميزة لا يقدمها أحد |
