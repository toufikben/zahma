### ⚠ ما لا تقوله — وهذا الأهم

**Mapbox لا يملك بيانات حركة حية للجزائر.** يعيد جدولاً أسبوعياً
نموذجياً ثابتاً: يوم + ساعة ← سرعة، يتكرّر كل أسبوع بلا تغيير.

قياس ذلك: كل يوم اثنين مطابق لكل يوم اثنين آخر بدقة **0.00 كم/س** على
58,790 زوجاً (مقطع × ساعة)، و100% منها متطابقة حرفياً.

**ولا يميّز أيام الأسبوع إما.** على لوحة ثابتة (5,399 مقطعاً مقيساً في
كل الأيام التسعة) الفرق عن أيام العمل: الجمعة **+0.18**، السبت **−0.73**،
الأحد **−0.14** كم/س. كلها داخل الضجيج. أقصى فرق ساعة-بساعة في منحنى
الجمعة: **1.17 كم/س**.

**وهذا خطأ بنيوي للجمعة بالذات:** الجمعة في الجزائر ليست يوم عمل عادي —
أهدأ صباحاً، وأذرو ظهراً (صلاة ثم زيارات). المصدر لا يعرف ذلك.

**الأثر:** لا نبيع «حركة حية». نبيع **نمطاً أسبوعياً نموذجياً**، ونسمّيه
باسمه. أي قياس حقيقي نجمع بأنفسنا يتفوّق عليه بالضرورة — لأنه يلتقط
حادثاً أو إغلاقاً لا يلتقطه الجدول.

الدقة الصادقة، بقسمة **مكانية** (مقاطع لم تُقس قط، 180,940 قياساً):

| الأساس | وسيط الخطأ | p90 | التحيز |
|---|---|---|---|
| سرعة OSM الحرة | 54.5% | 159.3% | +54.5% |
| أولوية الصنف المطلقة | 18.7% | 83.9% | +6.9% |
| **نسبة الأداء × الحرة** | **17.7%** | **59.2%** | **−0.4%** |

### ثلاثة قيود حقيقية اكتُشفت بالقياس

1. **`congestion` فارغ 100%** في الجزائر — لا أصناف ازدحام على مستوى
   المقطع. الخريطة تُبنى على السرعة المقاسة لا على تلوين غير موجود.
2. **Matrix API يرفض `depart_at`** بلا خطة مدفوعة — التنبؤ يحتاج
   استدعاء Directions لكل زوج، موازىً بـ4 عمال.
3. **المسار 15 خطوة لكن 328 حافة** — إسقاط الخطوات يقيس 4.5% من
   الطريق. نُسقط `annotation` بدلاً منها.

### وعيبان صامتان أُصلحا — كل واحد كان يُفسد النتيجة بلا صراخ

**1. التنبؤ كان يُقرأ كقياس حي.** كل صفوفنا بطوابع زمنية مستقبلية (جمعنا
بـ`depart_at`). استعلام «أحدث عينة حية» بلا حد أعلى التقط **674,137
صفاً مستقبلياً** وسمّاها قياساً حياً بثقة **0.9**. الإصلاح: حد أعلى
`ts_utc <= now` + استبعاد وسم `forecast` صراحةً.

**2. يوم كامل كان يُحذف بصمت.** `MIN_SAMPLES = 3` بلا رسالة. الجمعة لها
يوم واحد من البيانات (77,332 تركيبة بمتوسط **1.00** عينة) فحُذفت كلها.
`speed_profiles` كان 76,862 صفاً **كلها WORKDAY**. الإصلاح: تقرير
`dropped` مرئي، و`min_samples` معامل — والحد 1 صحيح هنا لأن جدول Mapbox
بلا ضجيج (رقم ثابت، فـn=1 اكتمال لا نقص).

**الأثر:** ملفات التعريف **76,862 ← 226,660 صفاً**. الجمعة على مسار باب
الزوار ← الوسط: **20.59 ← 23.92 دقيقة**.

## البدء السريع

```bash
python -m venv .venv && .venv/Scripts/activate     # Windows
pip install -e ".[dev]"

# قاعدة البيانات (PostGIS مطلوب)
zahma init-db

# الشبكة — ثقيل: شغّله في CI، لا محلياً
zahma build-network
zahma pick-corridors
zahma load-network
zahma router-stats --force

# بيانات تطوير (بلا مفاتيح)
zahma mock-fill --days 8 --segments 600
zahma rebuild-profiles

# المنتج
zahma estimate --from-lat 36.7167 --from-lon 3.1833 \
               --to-lat 36.7705 --to-lon 3.0589
zahma departure --from-lat 36.7167 --from-lon 3.1833 \
                --to-lat 36.7705 --to-lon 3.0589 --horizon 240 --step 30
```

### التوجيه — لماذا `scipy` لا `networkx`

القياس الفعلي على شبكة العاصمة:

| العملية | networkx | scipy CSR |
|---|---|---|
| بناء الرسم | 94 ث | 11 ث |
| توجيه واحد | 52 ث | **0.2 ث** |

`scipy.sparse.csgraph.dijkstra` مكتوب بلغة C. الفرق 260×، وهو ما يجعل
المنتج ممكناً: خادم واحد يخدم عشرات المستخدمين بدل عشرة خوادم.

### أولوية صنف الطريق — لماذا هي ضرورية

المسار داخل المدينة يمرّ عبر شوارع لا نقيسها (الحصص لا تكفي). بلا أولوية
الصنف يرجع كل مقطع غير مقيس إلى السرعة الحرة — **ثابتة لا تعرف الساعة** —
فيصبح منحنى الانطلاق خطاً مستقيماً.

جدول `class_profiles` ينقل سلوك الصنف الزمني من المقاطع المقيسة إلى غير
المقيسة. النتيجة: المنحنى يميّز بين 07:30 و11:30.

**سلسلة التراجع (لا تُعكس):** حي (0.9) ← ملف تعريف (0.6) ← صنف (0.35) ← حر (0.3).
